# 🌐 AICloud Web Dashboard & Mini App

Адаптивный современный веб-интерфейс для Telegram-бота **AICloud**.
Позволяет в реальном времени просматривать, фильтровать, искать и управлять всеми сохранёнными текстовыми заметками, файлами, голосовыми записями и фотографиями из базы данных PostgreSQL с векторным поиском `pgvector`.

---

## 🚀 Возможности веб-интерфейса

- 📱 **Полная адаптивность (100% Responsive & Telegram WebApp)**:
  - Идеально отображается на широкоформатных экранах, ноутбуках, планшетах и смартфонах.
  - Поддерживает безопасные зоны (`env(safe-area-inset-bottom)`), сенсорные жесты и Telegram WebApp SDK.
- ⚡ **Двухрежимный поиск**:
  - `⚡ Точный (PostgreSQL tsvector)` — мгновенная фильтрация по тексту и ключевым словам.
  - `🧠 ИИ Смысловой (pgvector 768-dim)` — ранжирование результатов по релевантности и косинусному расстоянию вектора Gemini.
- 🗂️ **Категории и папки (`group_name`)**:
  - Быстрая фильтрация по типу (`📝 Заметки`, `📁 Файлы`, `🖼️ Фото`, `🎙️ Голосовые`, `🔗 Ссылки`).
  - Фильтрация по папкам (`Работа`, `Проекты`, `Личное`, `Учеба`, `Идеи`).
- 🎙️ **Интерактивный плеер голосовых сообщений**:
  - Анимированная звуковая волна (waveform visualizer).
  - Отображение распознанного текста от **Whisper Turbo**.
  - Бейдж классификации намерения (напоминание, задача, поиск, заметка).
- 📁 **Просмотр и скачивание файлов**:
  - Бейджи типов файлов (.PDF, .ZIP, .SQL, .GO, .PNG, .DOCX).
  - Индикация размера файла и ссылки на оригинальное сообщение Telegram.
- 📋 **Интерактивные действия**:
  - Копирование текста в один клик.
  - Перемещение между папками.
  - Просмотр полных метаданных PostgreSQL (JSON, ID сообщений, модель векторов).
  - Удаление записей с диалогом подтверждения.
  - Добавление новых записей прямо из веб-панели с мгновенной индексацией.

## 🛠️ Как запустить

### Вариант 1: Вместе с ботом
Веб-сервер уже интегрирован в `main.go`. Просто запустите:
```bash
go run main.go
```
Веб-интерфейс автоматически откроется на:
👉 **`http://localhost:8080`**

Порт можно переопределить в файле `.env`:
```env
WEB_PORT=3000
```

### Вариант 2: Автономный запуск в браузере (Offline Preview)
Веб-приложение полностью работоспособно даже без запуска Go-сервера:
Просто откройте файл `web/index.html` двойным кликом в любом браузере (Chrome, Edge, Safari, Firefox). Приложение автоматически подгрузит демо-набор данных из `web/js/data.js`.

## 📲 Как подключить как Telegram Mini App (Web App)

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newapp`.
3. Выберите своего бота **AICloud**.
4. Введите название и описание приложения (например: `AICloud Vault`).
5. Загрузите иконку 640x360 px.
6. В поле **Web App URL** укажите URL вашего развернутого веб-сервера (с поддержкой HTTPS, например через Cloudflare Tunnel, ngrok или ваш домен: `https://your-domain.com`).
7. Готово! Теперь пользователи могут открывать хранилище кнопкой прямо внутри Telegram-чата.
