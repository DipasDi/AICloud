# AICloud 🧠

Персональное облако, база знаний и умный ассистент прямо в Telegram.

Сюда можно скидывать вообще всё: мысли, заметки, ссылки, файлы, фотографии и голосовые. Бот не просто складывает их в базу, а реально понимает смысл: по голосовому сам определяет, хочешь ты что-то сохранить или найти старое, а при поиске находит нужную запись, даже если ты забыл точные слова.

---

### Что умеет бот

- 🎙 **Голосовые с пониманием намерений**:
  - Кидаешь голосовое - бот транскрибирует аудио через Groq Whisper за полсекунды.
  - Дальше нейросеть за 0.2 сек анализирует смысл фразы:
    - Сказал *"Помоги найти про Дораму мой демон"* - бот сразу идет в поиск по базе.
    - Сказал *"Запиши код от домофона 4210"* - сразу сохраняет в базу как заметку.
    - Сказал *"Напомни завтра в 10 утра позвонить врачу"* - распознает задачу и время.
- ⚡ **Двухэтапный гибридный поиск**:
  1. Сначала ищет по точным словам через быстрый полнотекстовый поиск Postgres (`tsvector`). Это моментально (1 мс) и не тратит запросы к ИИ.
  2. Если точных слов нет, подключается нейросеть: переводит запрос в вектор и находит запись по смыслу через `pgvector` с быстрым HNSW-индексом.
- 🎯 **Быстрый переход к оригиналу**: если по запросу нашлась одна конкретная запись, бот реплаит прямо на неё в чате, чтобы можно было в один клик перенестись к нужному сообщению.
- 🎛 **Интерактивные кнопки под заметками**:
  - `⏰ Напомнить` - запланировать напоминание.
  - `📁 В папку` - раскидать по категориям или дополнить комментарий.
  - `🗑 Удалить` - быстро почистить ненужное.
  - `🙈 Скрыть` - убрать выпадающие результаты поиска, чтобы не засорять переписку.
- 🔒 **Приватность и легкий вес**: медиафайлы не скачиваются на диск сервера, а лежат в защищенном облаке Telegram. В базе хранятся только метаданные, ссылки и векторные представления.

### Как пользоваться

- `+ Текст заметки` - сохранить текстовую мысль.
- `+` в подписи к файлу или фото - сохранить медиа с комментарием.
- `? запрос` - найти запись. Например: `? рецепт шарлотки` или `? где-то были билеты`.
- **Голосовое сообщение** - просто надиктуй всё, что нужно. Бот сам поймет команду (поиск или сохранение).

### Стек технологий

- **Язык**: Go (Golang 1.22+)
- **Telegram фреймворк**: [telego](https://github.com/mymmrac/telego)
- **База данных**: PostgreSQL 17 + расширение `pgvector`
- **Драйвер БД**: `pgx/v5`
- **Распознавание речи (STT)**: Groq API (`whisper-large-v3-turbo`)
- **Классификация намерений**: Groq API (`qwen/qwen3.8-27b`) с fallback на OpenRouter (`nemotron-3-ultra-550b`)
- **Эмбеддинги для поиска по смыслу**: Google Gemini API (`gemini-embedding-001`, 768 dim, 1500 запросов/мин бесплатно)

### Как развернуть проект

#### 1. Клонируем репозиторий
```bash
git clone https://github.com/your-username/AICloud.git
cd AICloud
```

#### 2. Настраиваем переменные окружения
Создай файл `.env` в корне проекта:

```env
# Telegram Bot
TELEGRAM_TOKEN=твой_токен_от_BotFather

# База данных PostgreSQL с pgvector
DATABASE_URL=postgres://postgres:пароль@localhost:5432/AICloud?sslmode=disable

# Ключ Groq (для Whisper и быстрого анализа намерений)
QROQ_API_KEY=gsk_твой_ключ_от_groq

# Ключ Google AI Studio (для векторов и поиска без лимитов)
GEMINI_API_KEY=твой_ключ_от_google_ai_studio
EMBED_PROVIDER=gemini
EMBED_MODEL=models/gemini-embedding-001

# OpenRouter (как резервный fallback для моделей)
OPENROUTER_API_KEY=sk-or-v1-твой_ключ
INTENT_PROVIDER=groq
GROQ_INTENT_MODEL=qwen/qwen3.8-27b
INTENT_MODEL=nvidia/nemotron-3-ultra-550b-a55b:free
```

#### 3. Подготавливаем базу данных
Убедись, что в Postgres установлено расширение `vector`, и выполни скрипт инициализации:
```bash
psql -d AICloud -f sql/item.sql
```

#### 4. Запускаем бота
```bash
go run main.go
```
