# AICloud 🧠

Личное облако и база знаний прямо в Telegram с умным поиском по смыслу.

Сюда можно скидывать всё подряд: заметки, ссылки, файлы, фотки и голосовые. Бот сам всё разложит по полочкам, а когда понадобится что-то найти, поймёт даже смутный запрос без точных совпадений слов.

---

### Что умеет бот

- **Сохранение на лету**: пишешь мысль со знаком `+` (или кидаешь файл/картинку с подписью `+`), и она сохраняется в базу данных.
- **Двухэтапный гибридный поиск**:
  1. Сначала ищет по точным словам через быстрый поиск Postgres (`tsvector`). Это бесплатно и занимает 1 миллисекунду.
  2. Если точных слов не нашлось, подключается нейросеть через OpenRouter и ищет по смыслу через `pgvector`.
- **Быстрый переход к оригиналу**: если по запросу нашлась всего одна запись, бот отвечает реплаем на неё, так что можно в один клик перенестись к нужному сообщению в чате.
- **Расшифровка голосовых**: кидаешь голосовое сообщение, бот переводит аудио в текст и сохраняет как заметку.
- **Приватность**: сами медиафайлы не скачиваются на сервер, а хранятся в защищённом облаке Telegram. В базе лежат только тексты, ссылки и векторы.

---

### Как пользоваться

- `+ Текст заметки` - сохранить мысль или заметку.
- `+` в подписи к файлу или фото - сохранить вложение с комментарием.
- `? запрос` - найти запись. Например: `? рецепт пасты` или `? где-то были билеты`.
- Отправка голосового - бот переведёт аудио в текст.

---

### Стек

- **Язык**: Go (Golang)
- **Фреймворк Telegram**: [telego](https://github.com/mymmrac/telego)
- **База данных**: PostgreSQL с расширением `pgvector`
- **ИИ / Эмбеддинги**: OpenRouter API (модели эмбеддингов и чата)
- **Драйвер БД**: `pgx/v5`

### Как запустить проект

#### 1. Склонировать репозиторий
```bash
git clone https://github.com/your-username/AICloud.git
cd AICloud
```

#### 2. Настроить окружение
Создай файл `.env` в корне проекта:

```env
TELEGRAM_TOKEN=твой_токен_от_BotFather
DATABASE_URL=postgres://user:password@localhost:5432/aicloud?sslmode=disable
OPENROUTER_API_KEY=твой_ключ_openrouter
EMBED_MODEL=nvidia/nemotron-3.5-embed-8b:free
```

#### 3. Подготовить базу данных
Выполни скрипт создания таблиц и расширения `pgvector`:
```bash
psql -d aicloud -f sql/item.sql
```

#### 4. Запустить бота
```bash
go run main.go
```
